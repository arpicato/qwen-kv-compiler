# AGENTS.md

## Repository layout
- `services/` — one directory per deployable service, each with a `service.yaml`.
- `infra/` — terraform modules. Never edit generated files under `infra/.gen/`.
- `docs/adr/` — architecture decision records. Numbered, append-only.

## Build and test
- Node services use `pnpm`; Python services use `uv`. Do not mix.
- Run `pnpm -r test` for a full check; `pnpm --filter <name> test` for one service.
- Lint is `pnpm lint` (eslint) and `ruff check` for Python. Both must pass before commit.

## Conventions
- Commit messages follow Conventional Commits: `feat:`, `fix:`, `chore:`.
- One logical change per PR. Keep diffs under ~400 lines where possible.
- Never commit secrets. Secrets live in `infra/secrets/` (gitignored, SOPS-encrypted).
- Database migrations are append-only and must be reversible.

## Escalation
- If a test fails in a service you did not touch, do not "fix" it silently;
  report it. Cross-service breakage is owned by the #platform channel.
